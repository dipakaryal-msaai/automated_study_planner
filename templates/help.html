Help and User Guide

Learn how to use the study planner, understand guest versus account behavior, explore the REST API, and enable optional AI study insights and schedule optimization with Ollama.

1. Getting started

The app supports three common ways to begin:

Create an account

Best for saved progress, notifications, analytics, and API access.

Continue as guest

Good for trying the app quickly, but guest data is stored only in the browser session.

Use the REST API

Log in through the web flow first, then reuse the session cookie for JSON API calls.

2. Core study planner workflow

  1. Add courses from the Courses page and choose a difficulty from 1 to 5.
  2. Add deadlines from the Deadlines page and connect each one to a course.
  3. Generate a study plan from the dashboard to create scheduled study sessions.
  4. Mark sessions complete as you study so analytics and streak tracking stay accurate.
  5. Regenerate when plans change; completed sessions are kept as history while incomplete future sessions are replaced.

3. Accounts and guest mode

Mode What you get What to know
Guest Can add courses, deadlines, and generate a study plan. Data is temporary and disappears when the browser session ends.
Registered account Saved data, notifications, analytics, and API access. Best choice for ongoing use across devices and sessions.
Admin account Everything above plus the platform admin dashboard. Admin access is granted only when the logged-in email appears in the ADMIN_EMAILS environment variable.

Guest users can still explore the app, but the AI dashboard panel is shown only for logged-in accounts.

4. Notifications, analytics, AI, and admin

Notifications

Authenticated users can configure daily reminder time, email delivery, and an optional ntfy topic under Settings.

Analytics

The Analytics page shows completion rate, total study hours, streaks, subject breakdowns, and weekly trend charts.

AI insights

Logged-in users can optionally generate AI advice on the dashboard for deadline risk, weekly priorities, and study tips, and they can ask AI to optimize the pending schedule within built-in guardrails.

Admin dashboard

Admins can review platform totals, user activity, and weekly registrations from the protected /admin page.

5. REST API guide

The REST API uses the same session cookie as the web app. Log in through the browser or with curl, save the cookie jar, and send JSON requests to /api/v1.

Authentication flow

curl -i -c cookies.txt \ -X POST http://127.0.0.1:5000/auth/login \ -d "email=you@example.com" \ -d "password=your-password" curl -b cookies.txt http://127.0.0.1:5000/api/v1/auth/status

Create a course and generate a study plan

curl -b cookies.txt \ -H "Content-Type: application/json" \ -d '{"name":"Calculus","difficulty_level":4}' \ http://127.0.0.1:5000/api/v1/courses curl -b cookies.txt \ -H "Content-Type: application/json" \ -d '{"course_id":1,"due_date":"2026-04-25","task_type":"Exam"}' \ http://127.0.0.1:5000/api/v1/deadlines curl -b cookies.txt \ -H "Content-Type: application/json" \ -d '{}' \ http://127.0.0.1:5000/api/v1/study-plan/generate

Common API responses

  • 401: returned as JSON when the request is not authenticated.
  • 404: returned when the requested course, deadline, or study session does not exist in the current user scope.
  • 415: returned when a write request is missing a JSON body or the correct content type.

6. Optional AI setup

AI features are optional. The built-in planner still generates the base study schedule, and the optimizer only runs when you choose it.

If you are using a .env file, use plain KEY=VALUE lines like this:

AI_INSIGHTS_ENABLED=1 OLLAMA_BASE_URL=http://127.0.0.1:11434 OLLAMA_MODEL=llama3.2

Then run Ollama separately in your terminal, for example:

ollama serve ollama pull llama3.2

On the dashboard, Generate Insights produces advisory notes and reuses cached results when your planner data has not changed. Optimize Schedule can change pending session dates, durations, and count, must keep the total planned time within 20% of the base plan, cannot schedule past the allowed deadline window, and automatically retries once if the first AI draft fails validation. AI Study Chat answers planner-aware questions plus general study advice, and its transcript stays only in the current browser session.
